Budgie Desktop supports a wide-variety of keyboard combinations / shortcuts (commonly referred to as keybinds) to enable quick actions without taking your hands off the keyboard.

**Note:** This is not an exhaustive list, so be sure to open up Budgie Control Center, go to Keyboard, and choose "View and Customize Shortcuts" at the bottom of the panel!

These shortcuts assume a "stock" user experience and may differ if you use an operating system which ships Budgie Desktop with changes to the experience. Be sure to consult their documentation for any specifics as well!

Unless specified otherwise, `Super` refers to the "Windows" key. If you have multiple "Windows" keys, it will be the left one. You may also see it specified as `Win`

# Common Actions

## Budgie

| Action                           | Keybind                         |
| -------------------------------- | ------------------------------- |
| Clear notifications in Raven     | `Super+C`                       |
| Lock screen                      | `Super+L`                       |
| Log out                          | `Ctrl+Alt+Delete`               |
| Open Budgie Menu                 | `Super`                         |
| Open Budgie Run Dialog           | `Alt+F2`                        |
| Open Power Dialog                | `Super+Shift+P`                 |
| Open Raven widgets               | `Super+A`                       |
| Open Raven notifications         | `Super+N`                       |
| Open terminal                    | `Ctrl+Alt+T`                    |
| Show desktop                     | `Super+D`                       |
| Show or hide panels              | `Super+T`                       |
| Switch to next keyboard layout   | `Super+Space` or `Alt+Shift`    |
| Switch to previous keyboard layout | `Super+Shift+Space`           |
| Take screenshot of entire screen | `PrintScreen`                   |
| Take screenshot of an area       | `Ctrl+PrintScreen`              |

## Window Management

| Action                                      | Keybind                                  |
| ------------------------------------------- | ---------------------------------------- |
| Close window                                | `Alt+F4`                                 |
| Maximize window                             | `Super+Up Arrow`                         |
| Minimize window                             | `Super+H`                                |
| Move window to monitor above current        | `Super+Shift+Up Arrow`                   |
| Move window to monitor below current        | `Super+Shift+Down Arrow`                 |
| Move window to monitor left of current      | `Super+Shift+Left Arrow`                 |
| Move window to monitor right of current     | `Super+Shift+Right Arrow`                |
| Resize window                               | `Alt+F8`                                 |
| Snap window to left half of monitor         | `Super+Left Arrow`                       |
| Snap window to right half of monitor        | `Super+Right Arrow`                      |
| Switch to next window                       | `Alt+Tab`, `Super+Tab`, or `Alt+Esc`     |
| Switch to previous window                   | `Alt+Shift+Tab`, `Super+Shift+Tab`, or `Alt+Shift+Esc` |
| Toggle maximized                            | `Alt+F10`                                |
| Unmaximize window                           | `Super+Down Arrow` or `Alt+F5`           |

## Workspaces

| Action                                  | Keybind                                                         |
| --------------------------------------- | --------------------------------------------------------------- |
| Move window to first workspace          | `Super+Shift+Home`                                              |
| Move window to workspace on the left    | `Super+Shift+Page Up`, `Super+Shift+Alt+Left Arrow`, or `Ctrl+Shift+Alt+Left Arrow`    |
| Move window to workspace on the right   | `Super+Shift+Page Down`, `Super+Shift+Alt+Right Arrow`, or `Ctrl+Shift+Alt+Right Arrow` |
| Switch to first workspace               | `Super+Home`                                                    |
| Switch to last workspace                | `Super+End`                                                     |
| Switch to workspace on the left         | `Super+Page Up`, `Super+Alt+Left Arrow`, or `Ctrl+Alt+Left Arrow`    |
| Switch to workspace on the right        | `Super+Page Down`, `Super+Alt+Right Arrow`, or `Ctrl+Alt+Right Arrow` |

## Accessibility

| Action            | Keybind         |
| ----------------- | --------------- |
| Toggle magnifier  | `Super+Alt+8`   |
| Magnifier zoom in | `Super+Alt+=`   |
| Magnifier zoom out | `Super+Alt+-`  |

## Media and Hardware Keys

Keyboards with dedicated keys for the following actions work out of the box:

- Volume up, volume down, and mute
- Microphone mute
- Play/pause, stop, next track, and previous track
- Screen brightness up and down
- Lock screen
- Launch calculator, email client, home folder, media player, settings, or web browser
