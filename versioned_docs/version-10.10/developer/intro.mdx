export function DeveloperDocCards() {
  const { metadata } = useDoc();
  const items = useCurrentSidebarSiblings().filter((item) => item.docId !== metadata.id);
  return <DocCardList items={items} />;
}

This section contains documentation intended for developers and those interested in either contributing to Budgie Desktop or developing "widgets" for it. It covers Budgie Desktop 10.10.x, the currently supported release. Budgie Desktop 10.9.x and earlier are no longer supported, and Budgie 11 is still in development.

Before contributing, read our [Contributing](/developer/contributing) guidelines.
