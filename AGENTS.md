# Buddies of Budgie Docs - AI Agent Documentation

This document provides technical context for AI coding assistants working on the Buddies of Budgie documentation site. For contribution practices and AI policy, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Project Identity

- **Project**: Buddies of Budgie Documentation
- **Type**: Docusaurus documentation site
- **Languages**: TypeScript, React, MDX
- **Build system**: Yarn + Docusaurus
- **Package manager**: Yarn 4.x
- **Node requirement**: >= 24.0

## Build Quick Reference

```bash
# Install dependencies
yarn install

# Start dev server
yarn start

# Build
yarn build

# Typecheck
yarn typecheck

# Lint / format
yarn lint
```

## Documentation Conventions

### MDX Features

- **Admonitions**: `:::info`, `:::tip`, `:::warning`, `:::danger`, `:::note`
- **Tabs**: `<Tabs>` and `<TabItem>` from `@theme/Tabs` - used for OS/distro-specific content
- **Frontmatter**: YAML with `title`, `description`, `keywords`, `sidebar_label`, `sidebar_position`

### Frontmatter Format

```yaml
---
title: Page Title
description: Brief description for metadata
keywords:
  - keyword1
  - keyword2
sidebar_label: Sidebar Label
---
```

### Asset Organization

- Store assets in `assets/<document-name>/` folders relative to the document
- Prefer JPG for compression
- Avoid transparent PNGs (light/dark theme issues)

## Versioning

- **Current** (`docs/`): Unversioned, maps to Budgie 11 / "next"
- **10.10** (`versioned_docs/version-10.10/`): Latest stable (Wayland)
- **10.9.x** (`versioned_docs/version-10.9.x/`): Legacy (X11), unmaintained

Sidebars are autogenerated from directory structure. The main sidebar config is `sidebars.js`, version-specific overrides are in `versioned_sidebars/`.

## Attribution

See [CONTRIBUTING.md](CONTRIBUTING.md#ai-policy) for the full AI policy summary.

When an AI agent has assisted with **code or content changes**, add an `Assisted-by` trailer:

```
Assisted-by: <Tool>:<model-id>
```

The agent must analyze whether it actually assisted with changes. Mechanical tasks (committing, formatting, running commands) do not constitute assistance and do not require the trailer.

## Code Conventions

- Follow existing patterns in the codebase
- **TypeScript**: Standard React/TypeScript conventions
- **Components**: Functional components with hooks
- Refer to surrounding code in the same file/module for style guidance
