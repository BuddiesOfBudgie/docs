This section contains documentation for developers and those interested in contributing to Budgie 11, the next generation of Budgie Desktop.

:::info[Early development]
Budgie 11 is in the early stages of development. Expect documentation to be missing, or to only be added as we iterate on Budgie 11.
:::

To keep up with Budgie 11:

- Read the [Budgie 11 posts](https://buddiesofbudgie.org/blog/budgie-11/1) on our blog.
- Follow development on [our Forge](https://forge.moderndesktop.dev/BuddiesOfBudgie), where Budgie 11 and its components are developed and tracked.

Before contributing, read our [Contributing](./contributing.md) guidelines.

For the current stable release, see the [Budgie 10.10 developer documentation](/10.10/developer/intro).
