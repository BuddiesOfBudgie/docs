Found a bug?

Where to report depends on which component the issue is in. Before reporting, search the open issues and test with the latest release to see whether it is already fixed.

If Budgie crashed, include a backtrace so we can find the cause.

Reporting issues guideProviding backtraces

Where to report

  • GitHubBudgie Desktop 10.10 and its components, such as Budgie Control Center.
  • ForgeBudgie 11, and components shared with 10.10 such as budgie-desktop-services.
  • UpstreamScreen lockers such as gtklock and swaylock. How Budgie integrates with them comes to us.
